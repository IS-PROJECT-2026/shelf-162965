About Shelf

Shelf is a small reading site built to make public domain literature pleasant to read on a screen. Most free book sites bury the text under adverts, pagination, and account walls. This one does not.

Where the books come from

Every text on Shelf is sourced from Project Gutenberg, a volunteer effort that digitises works whose copyright has expired. These books belong to everyone. Nothing here is reproduced without the right to do so.

How it is built

Shelf is a static site written in hand-authored HTML, CSS, and a small amount of JavaScript. There is no framework, no build step, and no tracking. It is deployed through GitHub Pages from the main branch of its repository.

Reading comfort

Body text is set in a serif face at a measure of roughly sixty-five characters, which is the range at which most readers sustain attention longest. The reader view offers font size adjustment and a dark theme for low-light reading.
